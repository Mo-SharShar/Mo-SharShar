## Featured Project — Observability Platform

An end-to-end SRE and Observability engineering project built to collect, process, correlate, and visualize **metrics, logs, and traces** across Kubernetes workloads and applications. This is a personal, hands-on engineering project — not a production system — built to deepen practical SRE/Observability skills.

**Sample application:** Flask Payment API, instrumented with structured JSON logging, Prometheus metrics, and OpenTelemetry tracing (`request_id`, `trace_id`, `span_id`), including health/readiness endpoints and log-to-trace correlation.

**Architecture & Data Flow**

```
Application
    │
    ├── Metrics ───────────────► Prometheus / Mimir
    │
    ├── Logs ─────────────────► Alloy ─► Loki
    │
    └── Traces ───────────────► Alloy ─► Tempo
                                      │
                                      ▼
                                    Grafana
```

**What it demonstrates**
- Metrics collection, centralized logging, and distributed tracing
- Application instrumentation with OpenTelemetry
- Kubernetes observability and Golden Signals
- Dashboards, health checks, and readiness checks
- End-to-end telemetry pipelines (Metrics → Mimir, Logs → Loki, Traces → Tempo, Visualization → Grafana)

**Stack:** Kubernetes · Docker · Grafana · Prometheus · Loki · Mimir · Tempo · Grafana Alloy · OpenTelemetry
